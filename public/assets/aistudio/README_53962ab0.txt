HypeAthe Splash Background Pack

1. Copy the included public folder into your project root (merge files; do not replace your existing public folder).
2. Import HypeAtheSplashBackground.css in your existing splash/loading screen, or use the TSX wrapper around the existing loading content.
3. Keep existing authentication, loading state, navigation and timing logic unchanged.
4. The image is at /images/hypeathe-loading-bg.png.
